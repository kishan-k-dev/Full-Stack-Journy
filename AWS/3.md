# 3. EC2 — Virtual Server 🚀

## 1. What is EC2?

EC2 stands for **Elastic Compute Cloud**.

EC2 allows us to create a **virtual computer/server** on AWS.

Instead of buying a physical server, we can rent a virtual server from AWS.

### Simple Example

Your laptop = Your own computer

EC2 = A computer running in AWS that you access through the internet.

---

## 2. Why Do We Use EC2?

We can use EC2 to:

- Host websites
- Run Python applications
- Run backend APIs
- Deploy applications
- Run Docker containers
- Host services on the internet

---

## 3. What is an EC2 Instance?

An **EC2 instance** is basically a virtual server created inside AWS.

When creating an instance, we choose things like:

- Operating System
- CPU
- RAM
- Storage
- Network settings

Example:

```text
EC2 Instance
----------------
Ubuntu Linux
2 CPU
1 GB RAM
20 GB Storage
----------------
```

The exact specifications depend on the instance type we choose.

---

## 4. What is an AMI?

AMI stands for **Amazon Machine Image**.

It is a template used to create an EC2 instance.

Example:

```text
Ubuntu AMI
    ↓
Create EC2 Instance
    ↓
Ubuntu Server
```

We can choose different operating systems when creating an EC2 instance.

---

## 5. What is an Instance Type?

An **Instance Type** decides the basic hardware resources of the EC2 server.

It determines things like:

- CPU
- Memory
- Network performance

Simple idea:

```text
Small Instance → Small resources

Large Instance → More resources
```

For learning, we normally start with a small/free-tier-eligible option when available.

---

## 6. What is a Public IP?

A **Public IP** allows your EC2 server to be reached from the internet.

Example:

```text
EC2 Server
Public IP: 12.34.56.78
```

If a web application is running on the server, users can access it using the server's public IP.

Example:

```text
http://12.34.56.78
```

---

## 7. What is SSH?

SSH stands for **Secure Shell**.

SSH allows us to connect to a remote server and control it using the terminal.

Example:

```text
Your Laptop
     ↓
    SSH
     ↓
EC2 Ubuntu Server
```

After connecting, we can run Linux commands on the EC2 server.

Example:

```bash
ls
pwd
cd
sudo apt update
```

---

## 8. What is a Security Group?

A **Security Group** acts like a basic firewall for an EC2 instance.

It controls which network traffic is allowed to reach the server.

Common ports:

```text
Port 22  → SSH
Port 80  → HTTP
Port 443 → HTTPS
Port 8000 → Example application
```

We should only allow the ports that are actually required.

---

## 9. Simple EC2 Deployment Flow

A basic application deployment can look like this:

```text
Create EC2
    ↓
Choose Ubuntu
    ↓
Connect using SSH
    ↓
Install required software
    ↓
Upload application
    ↓
Run application
    ↓
Configure required port
    ↓
Access application from Internet
```

Later, we can use Docker to make deployment easier.

---

## 10. EC2 Example with a Python Application

Suppose we have a Python FastAPI application on our laptop.

```text
Python FastAPI App
        ↓
     Upload
        ↓
   EC2 Server
        ↓
     Run App
        ↓
    Internet
        ↓
      Users
```

The EC2 server runs our application and users can access it through the internet.

---

## 11. EC2 vs Your Laptop

| Your Laptop | EC2 |
|---|---|
| Physical computer | Virtual computer |
| You maintain the hardware | AWS manages the physical hardware |
| Mainly used personally | Can host applications |
| Usually accessed locally | Can be accessed remotely |
| Limited by your hardware | Resources can be selected based on need |

| Term | Simple Meaning |
|---|---|
| EC2 | AWS virtual server service |
| Instance | A virtual server |
| AMI | Template used to create a server |
| Instance Type | Defines server resources |
| Public IP | Address used to reach the server |

| Security Group | Controls network traffic |

## 13. Interview Questions

### Q1. What is EC2?

EC2 is an AWS service that provides virtual servers in the cloud.

### Q2. What is an EC2 instance?

An EC2 instance is a virtual server created using AWS EC2.

### Q3. What is AMI?

AMI stands for Amazon Machine Image. It is a template used to create an EC2 instance.

### Q4. What is SSH?

SSH stands for Secure Shell. It is used to securely connect to a remote server through a terminal.

### Q5. What is a Security Group?

A Security Group acts like a firewall and controls network traffic to an EC2 instance.

### Q6. What is a Public IP?

A Public IP is an IP address that can be used to access a server from the internet.

### Q7. Why do developers use EC2?

Developers use EC2 to deploy and run applications on cloud servers without buying physical servers.

## 15. Practical Task

Imagine you have a Python Flask or FastAPI application on your laptop.

Think about these steps:

1. Create an EC2 instance.
2. Choose an operating system such as Ubuntu.
3. Connect to the server using SSH.
4. Install the required software.
5. Upload your Python application.
6. Run the application.
7. Allow the required port.
8. Access the application through the server's IP address.

## Key Takeaways

- EC2 is used to create virtual servers in AWS.
- An EC2 instance is like a computer running in the cloud.
- AMI is a template used to create an instance.
- SSH is used to connect to the server.
- Security Groups control incoming and outgoing network traffic.
- EC2 can be used to host Python, web, and backend applications.
