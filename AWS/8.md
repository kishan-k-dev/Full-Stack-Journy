# 8. AWS — Revision & Interview Questions 🎯

## 1. What is Cloud Computing?

Cloud Computing means using servers, storage, databases, and software over the internet.

Example: Hosting an application on AWS.

## 2. What is AWS?

AWS stands for Amazon Web Services.

It is a cloud platform provided by Amazon.

## 3. Important AWS Services

| Service | Purpose |
|---|---|
| EC2 | Virtual server |
| S3 | File storage |
| IAM | Access management |
| RDS | Managed database |
| Lambda | Run code without managing servers |
| VPC | Private cloud network |
| CloudWatch | Monitoring |

## 4. Important AWS Concepts

| Concept | Simple Explanation |
|---|---|
| Region | Geographical AWS location |
| Availability Zone | Isolated location within a Region |
| Instance | Virtual server |
| AMI | Template used to create EC2 |
| Bucket | Container in S3 |
| Object | File in S3 |
| IAM User | User identity |
| IAM Policy | Permission rules |
| IAM Role | Temporary permissions |
| SSH | Secure remote connection |

## 5. Important Interview Questions

### Q1. What is Cloud Computing?

Cloud Computing provides computing resources such as servers and storage over the internet.

### Q2. What is AWS?

AWS is Amazon's cloud computing platform.

### Q3. What is EC2?

EC2 provides virtual servers in the cloud.

### Q4. What is S3?

S3 is used to store and retrieve files in the cloud.

### Q5. What is IAM?

IAM manages users and permissions in AWS.

### Q6. What is RDS?

RDS is a managed relational database service.

### Q7. What is an EC2 Instance?

It is a virtual server created using AWS EC2.

### Q8. What is an AMI?

AMI is a template used to create an EC2 instance.

### Q9. What is a Security Group?

It acts as a firewall and controls network traffic to AWS resources such as EC2 instances.

### Q10. What is SSH?

SSH is used to securely connect to remote servers.

### Q11. What is an S3 Bucket?

An S3 Bucket is a container used to store files.

### Q12. What is an IAM Role?

An IAM Role provides temporary permissions to a trusted user or AWS service.

### Q13. What is an AWS Region?

A Region is a geographical area where AWS has infrastructure.

### Q14. What is an Availability Zone?

It is an isolated location within an AWS Region.

### Q15. What is Lambda?

AWS Lambda allows us to run code without managing servers directly.

## 6. Real-Time Project Example

Imagine you build a Job Portal using Python FastAPI.

You can use AWS services like this:

```text
        Job Portal
            |
            ↓
      FastAPI Backend
            |
     -----------------
     |       |       |
     ↓       ↓       ↓
    EC2     RDS      S3
     |       |       |
     ↓       ↓       ↓
   Hosting Database  Files
```

IAM manages permissions for these resources.

CloudWatch helps monitor AWS resources.

Docker can package the FastAPI application before deployment.

## 7. Docker + AWS Connection

We already learned Docker.

Now understand how Docker and AWS work together.

```text
Python Application
        |
        ↓
      Docker
        |
        ↓
    Docker Image
        |
        ↓
    AWS EC2
        |
        ↓
   Application
        |
        ↓
      Users
```

Docker packages the application.

AWS provides the cloud infrastructure to run it.

## 8. Important Differences

### EC2 vs S3

| EC2 | S3 |
|---|---|
| Runs applications | Stores files |
| Virtual server | Cloud storage |
| Computing | Storage |

### EC2 vs RDS

| EC2 | RDS |
|---|---|
| Virtual server | Managed database |
| Runs applications | Stores structured data |
| Server management | Database management |

### IAM User vs IAM Role

| IAM User | IAM Role |
|---|---|
| Represents an identity | Provides temporary permissions |
| Can have long-term credentials | Uses temporary credentials |
| Used for user access | Commonly used by AWS services |
