# 7. Deploy a Python Application on AWS 🚀

## 1. What is Deployment?

Deployment means making an application available for users.

Example:

You build a Python FastAPI application on your laptop.

Initially, only you can access it locally.

After deployment, other people can access it through the internet.

## 2. What Do We Need?

For a basic AWS deployment:

- AWS Account
- EC2 Instance
- Ubuntu Server
- Python
- Application Code
- Security Group

## 3. Basic Deployment Flow

```text
Python Application
       |
       ↓
   AWS EC2
       |
       ↓
 Install Python
       |
       ↓
 Upload Project
       |
       ↓
 Run Application
       |
       ↓
 Internet
       |
       ↓
    Users
```

## 4. Step 1 — Create an EC2 Instance

1. Login to AWS.
2. Open the EC2 service.
3. Click Launch Instance.
4. Give your instance a name.
5. Select Ubuntu.
6. Choose an eligible instance type.
7. Configure the required security settings.
8. Launch the instance.

## 5. Step 2 — Connect to EC2

We can connect to an Ubuntu EC2 instance using SSH.

Example:

```bash
ssh -i "my-key.pem" ubuntu@YOUR_PUBLIC_IP
```

Replace:

- my-key.pem with your downloaded key file.
- YOUR_PUBLIC_IP with your EC2 public IP.

## 6. Step 3 — Install Python

After connecting to Ubuntu, run:

```bash
sudo apt update

sudo apt install python3 python3-pip python3-venv -y
```

These commands install Python and the tools needed to create a virtual environment.

## 7. Step 4 — Upload Your Application

You can upload your project using Git.

Example:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

Move into the project directory:

```bash
cd your-project
```

## 8. Step 5 — Install Project Dependencies

Create a virtual environment:

```bash
python3 -m venv venv
```

Activate it:

```bash
source venv/bin/activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

## 9. Step 6 — Run Your Application

For a basic FastAPI application:

```bash
uvicorn main:app --host 0.0.0.0 --port 8000
```

Here:

- main = Python file name.
- app = FastAPI application variable.
- 0.0.0.0 = Listen on all network interfaces.
- 8000 = Application port.

## 10. Step 7 — Configure Security Group

Open the EC2 Security Group.

Add an inbound rule for port 8000 if you want to access the example application directly.

For learning:

```text
Port 22   → SSH
Port 8000 → FastAPI example
Port 80   → HTTP
Port 443  → HTTPS
```

For production, use a proper web server or reverse proxy and secure access appropriately. Avoid exposing development servers directly.

## 11. Step 8 — Access Your Application

Open your browser:

```text
http://YOUR_PUBLIC_IP:8000
```

For FastAPI documentation:

```text
http://YOUR_PUBLIC_IP:8000/docs
```

Your application should be accessible if it is running and the network settings allow access.

## 12. Where Does Docker Help?

We already learned Docker.

Instead of manually installing Python and dependencies every time, we can package our application into a Docker image.

```text
Python Application
       |
       ↓
    Docker
       |
       ↓
    EC2 Server
       |
       ↓
    Internet
```

Docker makes application deployment more consistent.

## 13. Interview Questions

**Q1. What is deployment?**

Deployment means making an application available for users.

**Q2. Why do we use EC2 for deployment?**

EC2 provides virtual servers where we can run our applications.

**Q3. What is SSH used for?**

SSH is used to securely connect to a remote server.

**Q4. Why do we use Git on EC2?**

Git allows us to download and manage application source code from a repository.

**Q5. Why do we use port 8000?**

It is a common example port for running FastAPI applications.

**Q6. How does Docker help in deployment?**

Docker packages an application and its dependencies into a container, making deployment more consistent.


## 15. Practical Task

Try deploying a simple FastAPI application on an Ubuntu EC2 instance.

Understand these steps:

1. Create EC2.
2. Connect using SSH.
3. Install Python.
4. Download your project.
5. Install dependencies.
6. Run the application.
7. Access it through the public IP.

**Important:** EC2 instances and other AWS services may incur charges. Check current pricing, set a billing alert, and stop or delete resources when finished. Stopping an instance does not necessarily stop every related charge.
