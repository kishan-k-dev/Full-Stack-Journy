# 1. Introduction to Cloud Computing ☁️

## 1. What is Cloud Computing?

Cloud Computing means using computers, servers, storage, and software over the internet instead of owning physical hardware.

In simple words:

Instead of buying a computer and keeping it running 24/7, we can rent computing resources from cloud providers.

Example:
- Google Drive – Stores files in the cloud.
- Netflix – Uses cloud infrastructure to deliver videos.
- AWS – Provides servers, databases, and storage.

## 2. Why Do We Need Cloud Computing?

Traditional approach:
- Buy physical servers.
- Maintain hardware.
- Pay for electricity.
- Manage infrastructure.

Cloud approach:
- Rent resources when needed.
- Access services through the internet.
- Scale resources easily.
- Pay according to usage.

## 3. What is a Cloud Provider?

A Cloud Provider is a company that provides cloud services.

Popular providers:

1. AWS – Amazon Web Services
2. Microsoft Azure
3. Google Cloud Platform (GCP)

## 4. Types of Cloud Services

### IaaS – Infrastructure as a Service

Provides virtual servers, networking, and storage.

Example: AWS EC2

### PaaS – Platform as a Service

Provides a platform to build and deploy applications without managing all the server infrastructure.

Example: Google App Engine

### SaaS – Software as a Service

Ready-to-use software available through the internet.

Examples:
- Gmail
- Google Drive
- Microsoft 365

## 5. What is Scalability?

Scalability means increasing or decreasing resources based on application requirements.

Example:

If your website gets 100 users, a small server may be enough.

If it gets 1 lakh users, you may need more resources.

Cloud platforms make this easier.

## 6. Real-Time Example

Imagine you build a Python Flask application.

Without cloud:
- You need your own server.
- You must maintain it.
- Your application depends on that machine.

With cloud:
- You can rent a virtual server.
- Deploy your Flask application.
- Users can access it through the internet.

## 7. Advantages of Cloud Computing

- Lower initial hardware cost.
- Access from anywhere.
- Easy scalability.
- High availability options.
- Faster deployment.
- Pay-as-you-go pricing.

## 8. Interview Questions

**Q1. What is Cloud Computing?**

Cloud Computing is the delivery of computing services such as servers, storage, databases, and software over the internet.

**Q2. Name three cloud providers.**

AWS, Microsoft Azure, and Google Cloud.

**Q3. What is IaaS?**

Infrastructure as a Service provides virtual computing resources such as servers and networking.

**Q4. What is SaaS?**

Software as a Service provides ready-to-use applications over the internet.

**Q5. Why do companies use cloud computing?**

To reduce infrastructure management, scale applications, and deploy services faster.

## 9. Quick Revision

- Cloud Computing = Computing resources over the internet.
- AWS = Amazon Web Services.
- IaaS = Virtual infrastructure.
- PaaS = Application development platform.
- SaaS = Ready-to-use software.
- Scalability = Adjusting resources based on demand.
