# 2. Introduction to AWS ☁️

## 1. What is AWS?

AWS stands for **Amazon Web Services**.

It is a cloud computing platform provided by Amazon.

AWS allows us to use servers, storage, databases, and other computing services over the internet without buying physical hardware.

Example:

If you build a Python application, you can use AWS to host it so people can access it from anywhere.

## 2. Why Do We Use AWS?

- Host websites and applications.
- Store files and images.
- Create virtual servers.
- Manage databases.
- Scale applications when users increase.
- Pay for the resources we use.

## 3. Important AWS Services

| AWS Service | Simple Meaning |
|---|---|
| EC2 | Virtual computer/server |
| S3 | Store files and images |
| RDS | Managed database |
| IAM | Manage users and permissions |
| Lambda | Run code without managing servers |
| VPC | Private network in AWS |
| CloudWatch | Monitor applications and resources |

## 4. What is EC2?

EC2 stands for **Elastic Compute Cloud**.

It provides virtual servers in the cloud.

Imagine your laptop is a computer.

EC2 is like renting a computer from AWS that you can access remotely.

Example:
- Install Python.
- Upload your Flask application.
- Run your application on the EC2 server.

## 5. What is S3?

S3 stands for **Simple Storage Service**.

It is used to store files in the cloud.

Examples:
- Images
- Videos
- Documents
- Backups

Think of S3 as cloud storage similar to Google Drive, but designed for applications and developers.

## 6. What is IAM?

IAM stands for **Identity and Access Management**.

It controls who can access AWS resources and what actions they can perform.

Example:

A developer may have permission to access an EC2 server but not permission to delete billing settings.

## 7. AWS Global Infrastructure

AWS has infrastructure in different parts of the world.

### Region

A Region is a geographical area where AWS has data centers.

Example: Asia Pacific (Mumbai).

### Availability Zone

An Availability Zone is an isolated location within an AWS Region.

Simple example:

A company can run its application across multiple Availability Zones to improve availability.

## 8. Real-Time Example

Imagine you create a Python Flask website.

You can use:

- EC2 → Run your Python application.
- RDS → Store user information.
- S3 → Store uploaded images.
- IAM → Manage access permissions.
- CloudWatch → Monitor your application.

Together, these services help you run an application in the cloud.
