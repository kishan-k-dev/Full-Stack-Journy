# 4. Amazon S3 — Simple Storage Service ☁️

## 1. What is S3?

S3 stands for **Simple Storage Service**.

It is an AWS service used to store files in the cloud.

In simple words:

S3 is like Google Drive, where we can store files and access them whenever needed.

Examples:
- Images
- Videos
- PDF documents
- Resume files
- Application backups

---

## 2. Why Do We Use S3?

We use S3 to:

- Store application files.
- Store user-uploaded images.
- Store documents and PDFs.
- Keep backups.
- Access files through applications.

### Real-Time Example

Imagine you build a job portal.

Users upload their resumes.

Instead of storing all resumes directly on your application server, you can store them in AWS S3.

---

## 3. What is an S3 Bucket?

A **Bucket** is a container used to store files in S3.

Think of it like a folder where you keep your files.

Example:

```text
My S3 Bucket
    |
    |--- resume.pdf
    |--- profile.jpg
    |--- document.pdf
    |--- backup.zip
```

Every S3 bucket must have a globally unique name.

---

## 4. What is an S3 Object?

An **Object** is simply a file stored inside an S3 bucket.

Examples:
- photo.jpg
- resume.pdf
- video.mp4

Simple difference:

- Bucket = Container
- Object = File inside the container

---

## 5. How Does S3 Work?

```text
User
  |
  ↓
Python Application
  |
  ↓
AWS S3 Bucket
  |
  ↓
File Stored in Cloud
```

Our application sends a file to S3, and S3 stores it.

We can retrieve the file whenever required, depending on its permissions.

---

## 6. Important S3 Features

### 1. Scalability

S3 can store a large amount of data as your application grows.

### 2. Security

We can control who can access our files.

### 3. Durability

S3 is designed to protect stored data against data loss.

### 4. Backup

We can use S3 to store application backups.

---

## 7. Is S3 Public or Private?

S3 buckets are private by default.

We can control access using permissions.

Example:

```text
Private Bucket
     ↓
Only authorized users can access files.

Public Bucket
     ↓
Files may be accessible publicly if public access is allowed.
```

**Important:** Never make sensitive files such as resumes or personal documents publicly accessible.

---

## 8. S3 vs EC2

| EC2 | S3 |
|---|---|
| Virtual server | Cloud storage |
| Runs applications | Stores files |
| Provides computing power | Provides file storage |
| Example: Run Python API | Example: Store images |

```text
User Uploads Image
        ↓
FastAPI Application
        ↓

        ↓
```

Your application can retrieve the image whenever required.

## 10. Interview Questions

**Q1. What is AWS S3?**

S3 is an AWS cloud storage service used to store and retrieve files.

**Q2. What is an S3 Bucket?**

A bucket is a container used to store objects or files.

**Q3. What is an S3 Object?**

An object is a file stored inside an S3 bucket.

**Q4. Can we store images and videos in S3?**

Yes, S3 can store images, videos, documents, backups, and many other file types.

**Q5. Is an S3 bucket public by default?**

No. S3 buckets are private by default.

**Q6. What is the difference between EC2 and S3?**

EC2 is used to run applications on virtual servers, while S3 is used to store files.
