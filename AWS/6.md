# 6. AWS RDS — Relational Database Service 🗄️

## 1. What is RDS?

RDS stands for **Relational Database Service**.

It is an AWS service that helps us create and manage databases in the cloud.

In simple words:

Instead of installing and managing a database server ourselves, AWS manages many database administration tasks for us.

## 2. Why Do We Use RDS?

- Store application data.
- Manage databases in the cloud.
- Connect databases to applications.
- Create backups.
- Make database management easier.

## 3. Which Databases Does RDS Support?

AWS RDS supports several database engines:

- MySQL
- PostgreSQL
- MariaDB
- Oracle
- Microsoft SQL Server
- Amazon Aurora

## 4. Real-Time Example

Imagine you build a job portal.

You need to store:

- User details
- Login information
- Job descriptions
- Applications
- Recruiter details

You can use MySQL or PostgreSQL through AWS RDS.

## 5. How Does RDS Work?

```text
User
  |
  ↓
Frontend
  |
  ↓
Python FastAPI Backend
  |
  ↓
AWS RDS
  |
  ↓
Database
```

The backend communicates with RDS to save and retrieve information.

## 6. RDS vs MySQL

| MySQL | AWS RDS |
|---|---|
| Database software | Managed database service |
| Can be installed manually | AWS manages the database infrastructure |
| You manage server maintenance | AWS handles many maintenance tasks |
| Can run locally | Runs as a cloud database |

Important: RDS can use MySQL as its database engine.

## 7. Important RDS Features

- Automated backups.
- Database monitoring.
- Database scaling options.
- Managed maintenance.
- Multiple database engine options.

## 8. Interview Questions

**Q1. What is AWS RDS?**

RDS is an AWS service used to create and manage relational databases in the cloud.

**Q2. Which databases does RDS support?**

MySQL, PostgreSQL, MariaDB, Oracle, SQL Server, and Amazon Aurora.

**Q3. Can Python applications connect to RDS?**

Yes. Python applications can connect using database libraries and drivers.

**Q4. What is the difference between RDS and MySQL?**

MySQL is database software, whereas RDS is an AWS managed database service that supports MySQL.

**Q5. Why do we use RDS?**

To manage cloud databases more easily without handling all the underlying server maintenance ourselves.
