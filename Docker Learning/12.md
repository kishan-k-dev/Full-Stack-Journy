# 🧠 8. Sorting Algorithms

Sorting means arranging data in a particular order.

Usually:

```text
Ascending:
1 2 3 4 5

Descending:
5 4 3 2 1
```

Sorting is one of the most important topics in DSA.

It is used in:

- Searching
- Finding duplicates
- Finding minimum/maximum values
- Interval problems
- Two-pointer problems
- Database operations
- Ranking systems
- Data processing
- Interview coding problems

---

# 1. What is Sorting?

Suppose we have:

```text
[50, 20, 40, 10, 30]
```

After sorting in ascending order:

```text
[10, 20, 30, 40, 50]
```

Descending:

```text
[50, 40, 30, 20, 10]
```

The algorithm used to arrange these values is called a **sorting algorithm**.

---

# 2. Why Do We Need Sorting?

Imagine we have:

```text
[40, 10, 80, 20, 50]
```

Finding a value may require checking many elements.

After sorting:

```text
[10, 20, 40, 50, 80]
```

Now some algorithms, such as Binary Search, can work efficiently.

Sorting can also make other problems easier.

For example:

```text
Find duplicate values
Find pairs
Merge intervals
Find closest values
Find kth smallest/largest
```

Many of these become easier after sorting.

# 4. Bubble Sort

Bubble Sort repeatedly compares neighboring elements.

If they are in the wrong order, we swap them.

Example:

```text
[5, 3, 4, 1]
```

Compare:

```text
5  3
↑  ↑
```

5 > 3, so swap:

```text
[3, 5, 4, 1]
```

Next:

```text
3  5  4
   ↑  ↑
```

5 > 4, swap:

```text
[3, 4, 5, 1]
```

Next:

```text
[3, 4, 1, 5]
```

The largest value gradually moves toward the end.

That's why it is called:

```text
Bubble Sort
```

The larger values "bubble" toward the end.

---

# 5. Bubble Sort Example

Starting array:

```text
[5, 3, 4, 1]
```

First pass:

```text
5 3 → swap
3 5 4 1

5 4 → swap
3 4 5 1

5 1 → swap
3 4 1 5
```

After first pass:

```text
[3, 4, 1, 5]
```

Largest value `5` is now in its correct position.

Second pass:

```text
3 4 → no swap

4 1 → swap

[3, 1, 4, 5]
```

Third pass:

```text
3 1 → swap

[1, 3, 4, 5]
```

Sorted:

```text
[1, 3, 4, 5]
```

---

# 6. Bubble Sort Code

```python
arr = [5, 3, 4, 1]

n = len(arr)

for i in range(n):
    for j in range(0, n - i - 1):

        if arr[j] > arr[j + 1]:
            arr[j], arr[j + 1] = arr[j + 1], arr[j]

print(arr)
```

Output:

```text
[1, 3, 4, 5]
```

---

# 7. Optimized Bubble Sort

We can stop early if no swaps happen.

```python
arr = [1, 2, 3, 4, 5]

n = len(arr)

for i in range(n):

    swapped = False

    for j in range(0, n - i - 1):

        if arr[j] > arr[j + 1]:
            arr[j], arr[j + 1] = arr[j + 1], arr[j]
            swapped = True

    if not swapped:
        break

print(arr)
```

If the array is already sorted:

```text
[1, 2, 3, 4, 5]
```

the algorithm can stop early.

# 9. Selection Sort

Selection Sort works by repeatedly finding the smallest element and placing it in the correct position.

Example:

```text
[5, 3, 4, 1, 2]
```

Find the smallest:

```text
1
```

Put it at the beginning:

```text
[1, 3, 4, 5, 2]
```

Now consider the remaining part:

```text
[3, 4, 5, 2]
```

Smallest:

```text
2
```

Put it next:

```text
[1, 2, 4, 5, 3]
```

Continue:

```text
[1, 2, 3, 5, 4]
```

Finally:

```text
[1, 2, 3, 4, 5]
```

---

# 10. Selection Sort Code

```python
arr = [5, 3, 4, 1, 2]

n = len(arr)

for i in range(n):

    min_index = i

    for j in range(i + 1, n):

        if arr[j] < arr[min_index]:
            min_index = j

    arr[i], arr[min_index] = arr[min_index], arr[i]

print(arr)
```

Output:

```text
[1, 2, 3, 4, 5]
```

---

     ↓

```text

 ↑

[1 3 4 5 2]
   ↑

[1 2 4 5 3]
     ↑
Find minimum = 3

[1 2 3 5 4]

```

# 15. Insertion Sort Code

```python
arr = [5, 3, 4, 1, 2]

for i in range(1, len(arr)):

    key = arr[i]

    j = i - 1

    while j >= 0 and arr[j] > key:

        arr[j + 1] = arr[j]

        j -= 1

    arr[j + 1] = key

print(arr)
```

Output:

```text
[1, 2, 3, 4, 5]
```

# 19. Merge Sort

Merge Sort uses the:

```text
Divide and Conquer
```

strategy.

It divides the array into smaller parts.

Example:

```text
[8, 3, 5, 4]
```

Divide:

```text
[8, 3]    [5, 4]
```

Divide again:

```text
[8] [3]   [5] [4]
```

Then merge sorted pieces:

```text
[3, 8]    [4, 5]
```

Finally:

```text
[3, 4, 5, 8]
```

---

# 20. Merge Sort Mental Model

```text
              [8 3 5 4]
                  |
          ┌───────┴───────┐
          ↓               ↓
       [8 3]            [5 4]
        /  \             /  \
       ↓    ↓           ↓    ↓
      [8]  [3]         [5]  [4]
        \    /           \    /
         [3 8]            [4 5]
              \           /
               \         /
                [3 4 5 8]
```

---

# 21. Why Is Merge Sort Called Divide and Conquer?

Because it:

```text
Divide
  ↓
Break problem into smaller problems

Conquer
  ↓
Solve smaller problems

Combine
  ↓
Merge results
```

This pattern is used in many algorithms.

---

# 22. Merge Sort Code

```python
def merge_sort(arr):

    if len(arr) <= 1:
        return arr

    mid = len(arr) // 2

    left = merge_sort(arr[:mid])
    right = merge_sort(arr[mid:])

    return merge(left, right)


def merge(left, right):

    result = []

    i = 0
    j = 0

    while i < len(left) and j < len(right):

        if left[i] <= right[j]:

            result.append(left[i])
            i += 1

        else:

            result.append(right[j])
            j += 1

    result.extend(left[i:])
    result.extend(right[j:])

    return result


arr = [8, 3, 5, 4, 1, 2]

arr = merge_sort(arr)

print(arr)
```

Output:

```text
[1, 2, 3, 4, 5, 8]
```

---

# 23. Merge Sort Complexity

```text
O(n log n)
```

Average:

```text
O(n log n)
```

Worst:

```text
O(n log n)
```

```text
O(n)
```

---

# 24. Why O(n log n)?

The array is repeatedly divided.

For example:

```text
n
↓
n/2
↓
n/4
↓
n/8
...
```

The number of levels is approximately:

```text
log₂(n)
```

At each level, merging processes approximately:

```text
n
```

elements.

So:

```text
n × log n

= O(n log n)
```

# 25. Quick Sort

Quick Sort is another:

```text
Divide and Conquer
```

algorithm.

It chooses a value called a:

```text
Pivot
```

Then rearranges elements around the pivot.

Example:

```text
[6, 3, 8, 2, 5]
```

Suppose pivot:

```text
5
```

Elements smaller than 5:

```text
3, 2
```

Elements greater than 5:

```text
6, 8
```

Conceptually:

```text
[3, 2] [5] [6, 8]
```

Then we recursively sort the left and right parts.

---

# 26. Quick Sort Mental Model

```text
              [6 3 8 2 5]
                    |
                 Pivot 5
                    |
          ┌─────────┴─────────┐
          ↓                   ↓
       Smaller             Greater
       [3 2]                [6 8]
          ↓                   ↓
       Sort                  Sort
          ↓                   ↓
        [2 3]               [6 8]
             \              /
              \            /
               [2 3 5 6 8]
```

---

# 27. Quick Sort Code

One simple Python implementation:

```python
def quick_sort(arr):

    if len(arr) <= 1:
        return arr

    pivot = arr[len(arr) // 2]

    left = [x for x in arr if x < pivot]
    middle = [x for x in arr if x == pivot]
    right = [x for x in arr if x > pivot]

    return quick_sort(left) + middle + quick_sort(right)


arr = [6, 3, 8, 2, 5]

print(quick_sort(arr))
```

Output:

```text
[2, 3, 5, 6, 8]
```

This version is easy to understand, but it creates additional lists. In-place Quick Sort implementations are different.

---

# 28. Quick Sort Complexity

Average:

```text
O(n log n)
```

Worst case:

```text
O(n²)
```

The worst case can happen when pivot choices repeatedly produce very unbalanced partitions.

Space complexity depends on the implementation.

For recursive in-place implementations, recursion stack space is typically:

```text
O(log n) average
O(n) worst case
```

---

# 29. Merge Sort vs Quick Sort

| Feature | Merge Sort | Quick Sort |
|---|---|---|
| Average | O(n log n) | O(n log n) |
| Worst | O(n log n) | O(n²) |
| Main idea | Divide + merge | Pivot + partition |
| Extra array space | Usually O(n) | Can be in-place |
| Stable | Yes, with standard stable implementation | Usually not |
| Important concept | Merging | Partitioning |

# 30. What is Stability?

A sorting algorithm is **stable** if equal elements maintain their original relative order.

Example:

```text
Students:

A → Marks 80
B → Marks 70
C → Marks 80
```

Sort by marks:

```text
B → 70
A → 80
C → 80
```

A and C both have 80.

If A was originally before C and remains before C, the sort preserved their relative order.

That's stability.

---

# 31. Stable Sorting

Common examples:

```text
Bubble Sort → Stable
Insertion Sort → Stable
Merge Sort → Stable
```

Selection Sort and Quick Sort are not generally stable in their usual implementations.

# 50. Interview Questions & Answers

## Q1. What is sorting?

**Answer:**

Sorting is the process of arranging data in a specific order, such as ascending or descending order.

---

## Q2. What is Bubble Sort?

**Answer:**

Bubble Sort repeatedly compares adjacent elements and swaps them when they are in the wrong order.

---

## Q3. What is the worst-case complexity of Bubble Sort?

**Answer:**

The worst-case time complexity is:

```text
O(n²)
```

---

## Q4. What is Selection Sort?

**Answer:**

Selection Sort repeatedly finds the smallest element from the unsorted portion and places it at the correct position.

---

## Q5. What is Insertion Sort?

**Answer:**

Insertion Sort builds the sorted portion one element at a time by inserting each new element into its correct position.

---

## Q6. When is Insertion Sort useful?

**Answer:**

It can be useful for small or nearly sorted data because its best-case time complexity is O(n).

---

## Q7. What is Merge Sort?

**Answer:**

Merge Sort is a divide-and-conquer sorting algorithm that divides the array into smaller parts, sorts them, and merges the sorted parts.

---

## Q8. What is the complexity of Merge Sort?

**Answer:**

Its time complexity is:

```text
O(n log n)
```

in the best, average, and worst cases.

---

## Q9. What is Quick Sort?

**Answer:**

Quick Sort selects a pivot, partitions the elements around the pivot, and recursively sorts the resulting parts.

---

## Q10. What is the worst-case complexity of Quick Sort?

**Answer:**

The worst-case time complexity is:

```text
O(n²)
```

This can happen when partitions are repeatedly very unbalanced.

---

## Q11. Which is better: Merge Sort or Quick Sort?

**Answer:**

It depends on the requirements.

Merge Sort guarantees O(n log n) time but commonly uses additional memory for arrays.

Quick Sort can be implemented in-place and often performs well, but its worst-case time complexity is O(n²).

---

## Q12. What is a stable sorting algorithm?

**Answer:**

A stable sorting algorithm preserves the relative order of elements that have equal keys.

---

## Q13. Is Bubble Sort stable?

**Answer:**

Yes, the standard implementation of Bubble Sort can be stable.

---

## Q14. Is Merge Sort stable?

**Answer:**

Yes, a standard Merge Sort implementation can be stable.

---

## Q15. What is the difference between sorted() and sort() in Python?

**Answer:**

`sorted()` returns a new sorted list, while `.sort()` sorts the existing list in-place.

Example:

```python
result = sorted(arr)
```

versus:

```python
arr.sort()
```

---

## Q16. How do you sort in descending order in Python?

**Answer:**

```python
arr.sort(reverse=True)
```

or:

```python
sorted(arr, reverse=True)
```

## Q17. Why is sorting useful before using two pointers?

**Answer:**

Sorting gives the elements an ordered structure, allowing the two pointers to move intelligently based on whether the current value is too small or too large.

---

## Q18. Is sorting always necessary?

**Answer:**

No. Some problems can be solved more efficiently using hashing, counting, heaps, or other techniques without sorting.
