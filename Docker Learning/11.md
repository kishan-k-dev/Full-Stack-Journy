# 🧠 11. Dynamic Programming (DP)

Dynamic Programming (DP) is a technique used to solve problems by **breaking them into smaller subproblems and storing their results** so we don't calculate the same thing again.

---

# 1. Why Dynamic Programming?

Consider Fibonacci:

```text
F(n) = F(n-1) + F(n-2)
```

Normal recursion calculates the same values many times.

```text
          F(5)
         /    \
       F(4)    F(3)
       / \     / \
     F(3) F(2) F(2) F(1)
```

`F(3)` and `F(2)` are calculated repeatedly.

DP stores the results and reuses them.

---

# 2. Two Main Properties of DP

A problem is often suitable for DP when it has:

### 1. Overlapping Subproblems

The same smaller problem appears multiple times.

Example:

```text
F(5)
 ├── F(4)
 │    └── F(3)
 └── F(3)  ← repeated
```

### 2. Optimal Substructure

The best solution to a problem can be built from the best solutions of its smaller subproblems.

---

# 3. Two Main DP Approaches

```text
Dynamic Programming
       |
       +---- Memoization
       |
       +---- Tabulation
```

---

# 4. Memoization

Memoization means:

> Recursion + storing previously calculated results.

Example:

```python
def fibonacci(n, dp):

    if n <= 1:
        return n

    if dp[n] != -1:
        return dp[n]

    dp[n] = fibonacci(n - 1, dp) + fibonacci(n - 2, dp)

    return dp[n]


n = 6
dp = [-1] * (n + 1)

print(fibonacci(n, dp))
```

Output:

```text
8
```

Here `dp` stores previously calculated values.

---

# 5. Tabulation

Tabulation uses an iterative approach.

We start from the smallest problems and build the answer.

```python
def fibonacci(n):

    if n <= 1:
        return n

    dp = [0] * (n + 1)

    dp[0] = 0
    dp[1] = 1

    for i in range(2, n + 1):
        dp[i] = dp[i - 1] + dp[i - 2]

    return dp[n]


print(fibonacci(6))
```

Output:

```text
8
```

---

# 6. Memoization vs Tabulation

| Feature | Memoization | Tabulation |
|---|---|---|
| Approach | Top-down | Bottom-up |
| Usually uses recursion | Yes | No |
| Uses DP array | Yes | Yes |
| Easy to write from recursion | Yes | Sometimes |
| Stack usage | Yes | No |

# 7. Fibonacci with DP

Fibonacci:

```text
0 1 1 2 3 5 8 13
```

Formula:

```text
dp[i] = dp[i-1] + dp[i-2]
```

Complexity:

```text
Time  = O(n)
Space = O(n)
```

---

# 8. Space Optimization

For Fibonacci, we only need the previous two values.

So we don't need the entire DP array.

```python
def fibonacci(n):

    if n <= 1:
        return n

    prev2 = 0
    prev1 = 1

    for i in range(2, n + 1):
        current = prev1 + prev2
        prev2 = prev1
        prev1 = current

    return prev1


print(fibonacci(6))
```

Output:

```text
8
```

Complexity:

```text
Time  = O(n)
Space = O(1)
```

# 9. Climbing Stairs

Problem:

You can climb either:

```text
1 step
```

or:

```text
2 steps
```

How many different ways can you reach step `n`?

For example:

```text
n = 3
```

Ways:

```text
1 + 1 + 1
1 + 2
2 + 1
```

Answer:

```text
3
```

The recurrence is:

```text
dp[n] = dp[n-1] + dp[n-2]
```

---

# 10. Climbing Stairs Code

```python
def climb_stairs(n):

    if n <= 2:
        return n

    prev2 = 1
    prev1 = 2

    for i in range(3, n + 1):
        current = prev1 + prev2
        prev2 = prev1
        prev1 = current

    return prev1


print(climb_stairs(5))
```

Output:

```text
8
```

# 11. 0/1 Knapsack

A classic DP problem.

You have:

```text
Items
Weights
Values
Maximum capacity
```

Goal:

> Select items to get maximum value without exceeding the capacity.

Example:

```text
Weights = [2, 3, 4]
Values  = [4, 5, 7]

Capacity = 5
```

Possible selection:

```text
Weight = 2 + 3 = 5
Value  = 4 + 5 = 9
```

Answer:

```text
9
```

# 13. How to Identify a DP Problem

Ask:

```text
1. Are there smaller subproblems?
2. Are the same subproblems repeated?
3. Can I store their results?
4. Can the final answer be built from smaller answers?
```

If the answer is mostly **yes**, DP may be applicable.

---

# 14. Common DP Pattern

```text
Define state
     ↓
Find base case
     ↓
Find recurrence
     ↓
Store results
     ↓
Build final answer
```

Example:

```text
dp[i] = answer for problem i
```

Then:

```python
dp[i] = ...
```

---

# 15. Common Mistakes

### Mistake 1

Using DP when there are no overlapping subproblems.

### Mistake 2

Incorrect base cases.

### Mistake 3

Wrong recurrence relation.

### Mistake 4

Using unnecessary memory.

### Mistake 5

Not understanding what `dp[i]` represents.

Always define:

```text
What does dp[i] mean?
```

before writing the code.

# 16. Interview Questions

### Q1. What is Dynamic Programming?

**Answer:**

Dynamic Programming solves problems by storing results of smaller subproblems and reusing them to avoid repeated calculations.

### Q2. What are the two main DP approaches?

**Answer:**

Memoization and Tabulation.

### Q3. What is Memoization?

**Answer:**

A top-down approach that uses recursion and stores already calculated results.

### Q4. What is Tabulation?

**Answer:**

A bottom-up approach that iteratively builds solutions from smaller subproblems.

### Q5. Why is DP faster than normal recursion?

**Answer:**

DP avoids recalculating the same subproblems by storing their results.
